# dengue-clima-python-bh
Projeto de Machine Learning que integra dados climáticos (INMET) e dados de notificação de dengue (DATASUS/SINAN) para classificar o risco semanal de dengue em Belo Horizonte. Usa engenharia de features com variáveis de atraso (lags) climáticos e um algoritmo de classificação (Regressão Logística e Random Forest) para indicar se uma semana é de Alto ou Baixo Risco.
